# Brand assets

`duolingo.webp` preserves the original full-color Duo avatar served by Duolingo's
official blog: https://blog.duolingo.com/assets/images/default_avatar.png

The original 600 × 600 PNG is downsampled to 64 × 64 lossless WebP for this small
profile link. It is displayed in its original colors instead of through the
monochrome icon mask. Duolingo owns the mark; it identifies the linked profile.
