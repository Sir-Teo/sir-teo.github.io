# Recorded review data

Source: Sir-Teo/blogs, commit `39a663c6f226b0c4c2b51d0c1612c16c87419af8`.

- `chess.json`: the Club vs Intermediate game from `assets/data/web-chess-demo.json`. The blog's `_tools/web-chess-demo` ran the actual Web Chess review pipeline and Stockfish 18 Lite WASM at depth 16. FENs, principal variations, scores and move classifications are preserved.
- `xiangqi.json`: the single game from `assets/data/web-xiangqi-demo.json`, generated by Pikafish dev-20260219-beeca5cc. Board positions are replayed from that move record. Chinese notation and the evaluation curve use the blog's bundled Web Xiangqi helpers. Depth 16.
- `go.json`: `game` from `assets/data/web-katrain-demo.json`, generated with Web KaTrain's own small g170 b6c96 model, 200 visits, seed 2, 9×9 Chinese rules, komi 7. Scores and candidate scores are Black-positive. Each source frame's `move` is outgoing: the previous frame's move is highlighted on the current board. Planted mistakes remain labeled. This small model is for demonstration, not strong Go advice.

Source-file SHA-256 digests are stored in the JSON records. Regenerate with `node scripts/sync-review-previews.mjs`; the generator takes a blog checkout as its optional first argument. No search engine is shipped or executed by this viewer.

`chess-pieces.svg` is the same Colin M. L. Burnett artwork used in the blog and Web Chess through react-chessboard. The source blog's `_tools/web-chess-demo/pieces.cjs` attributes the artwork to Cburnett (GPL/BSD/GFDL on Wikimedia Commons) and the component package to react-chessboard (MIT). The SVG geometry is unchanged, wrapped as reusable symbols.
